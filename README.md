## 📋 Sobre o Projeto

Página de captura (landing page) criada para anunciar um workshop de marketing. O objetivo é apresentar o evento de forma atrativa e coletar o interesse dos participantes através de um formulário de inscrição.

### Funcionalidades:

- Cabeçalho com chamada principal de impacto
- Formulário de inscrição (Nome, E-mail e Local)
- Seção do palestrante com foto e biografia
- Design responsivo básico
- Visual moderno com cores contrastantes
